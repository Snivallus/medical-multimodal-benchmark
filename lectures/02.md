### 从数据到智慧：知识工程的问题起点

#### 数据的由来：结绳记事与物理符号

课程从“数据”讲起，因为大模型本质上也是数据驱动的，没有数据就谈不上智能。早期人类没有现代意义上的数据概念，只能借助物理符号记录事物。波斯王远征时要求守桥60天，为了不弄错天数，采用在绳子上打60个结的方法，每过一天解开一个，全部解完即可撤退。我国早期一些民族也用羊毛疙瘩、鸡毛、辣椒、木炭等不同标识表示消息的紧急程度和重要性。

这些例子说明：**数据是人们用于记录事物情况的物理符号**。符号本身没有天然意义，是人赋予其特定含义，并形成共同约定。数据承载了信息，而信息是数据中所包含的意义。知识工程正是为了处理大量数据、挖掘有价值信息而诞生的。

#### 数据、信息、知识、智慧

课程用一层层递进的关系说明：

| 层次 | 含义                                         | 理解能力 |
| ---- | -------------------------------------------- | -------- |
| 数据 | 原始素材，对客观事物的形式化表示             | 理解力   |
| 信息 | 加工处理后有逻辑的数据                       | 理解关系 |
| 知识 | 从相关信息中过滤、提炼、加工得到的有价值信息 | 理解模式 |
| 智慧 | 关注未来，具有预测能力                       | 理解原理 |

因此，从“数据”到“智慧”的炼金术是知识工程的核心思想：数据是散落的矿石，信息是分类的矿石，知识是提炼的纯金，智慧是运用知识进行推理、判断和创造，解决复杂实际问题的能力。

#### 广谱关联大数据与数据形态

“广谱关联大数据”强调生产实际中各行各业、各领域数据之间存在密切而复杂的联系。若只使用小范围数据做决策，结论可能有偏见；若能获得更广泛、更全貌的数据，并进行充分关联，决策会更有价值。这也与知识表示、知识图谱的发展密切相关。

大数据常以**4V**概括：Variety、Velocity、Volume、Value。按结构化程度，数据可分为：

- **结构化数据**：关系表、二维表、图数据、知识库数据等，结构清晰，可直接关联分析和提取。
- **半结构化数据**：XML、JSON、简历数据、网页等，既有一定标签与结构信息，又有自由文本。简历中既有照片、求职意向、教育背景等结构化栏目，也有技能、项目经验、自我评价等文本描述。
- **非结构化数据**：文本、图片、音频、视频等，蕴含丰富隐性知识与情感信息。

还可以区分静态数据与流数据。PPT 举到“每10分钟机器人自己造个机器人”的新闻，说明工业人形机器人超级智慧工厂中，数据持续产生、实时流动。

### 知识工程与人工智能

#### 知识工程的定义与核心思想

知识工程在20世纪60至70年代开始提出，目标是让机器具备像人一样解决问题、思考的能力。早期典型系统是**专家系统**，希望系统在某一领域像医生、律师、教师一样进行诊断、判断与决策。相关概念还包括：

- **计算智能**：计算机强大的计算能力及其基础上体现出的智能感。
- **商务智能**：利用数据仓库、OLAP、数据挖掘等技术进行数据分析，辅助商业决策。该词在业界提得较多。
- **认知科学**：从人类认知角度研究智能。

知识工程早期定义为：使用人工智能原理和方法构造专家系统的一门工程性学科。随着计算智能和商务智能出现，知识工程发展为利用计算机智能构造各类高性能知识系统，专家系统只是知识系统的一种类型。

更具体的定义是：**知识工程以知识为处理对象，研究知识系统的知识表示、处理和应用的方法与开发工具**。它是人工智能、计算智能、商务智能和认知科学等多学科交叉发展的结果，比人工智能等具有更强的实用性。

知识工程的核心问题包括：知识的有效获取、知识表示、知识推理与应用。费根鲍姆（Edward Albert Feigenbaum）于1977年在第五届国际人工智能会议上以《人工智能的艺术：知识工程的课题及实例研究》为题首先提出知识工程概念，被誉为“专家系统与知识工程之父”。他认为知识工程是一门艺术，应用人工智能原理和方法求解那些需要专家知识才能解决的问题；专家知识的获取、表达和合理应用，以及构造和解释推理过程，是设计知识系统的重要技术问题。

#### 知识工程与知识图谱的区别

一个常见误区是把知识工程与知识图谱混为一谈。课程强调：

- **知识图谱**是静态载体、结构化知识的仓库，侧重于知识的标准化表示与关联存储，解决“知识如何存储”的问题，聚焦表示层与存储层。
- **知识工程**是动态的构建与应用体系，是构建、管理和应用知识的系统性工程方法论，解决“如何构建智能系统”的问题，覆盖知识获取、融合、推理与应用的全生命周期。

核心结论是：知识图谱是知识工程的重要组成部分和核心载体，但知识工程的范畴远不止于此。知识图谱可视为知识工程的一种实践形态或具体实例。

#### 知识工程的演进脉络

知识工程的演进可概括为从规则引擎到认知智能：

1. **专家系统时代（1960s—1980s）**  
   核心技术是基于规则的系统，采用产生式规则和 IF-THEN 形式，依靠人工编写逻辑规则驱动推理。知识表示将专家经验转化为机器可执行逻辑表达。典型系统包括 DENDRAL（分子结构推断）、MYCIN（血液感染诊断系统）。阶段特点是依赖领域专家人工编码，知识封闭，维护成本高，灵活性不足。

2. **本体工程与语义 Web（1990s—2010s）**  
   核心技术是本体论建模与语义 Web 技术栈，使用 RDF 描述三元组关系，OWL 定义复杂类层次与属性约束。行业标杆包括 W3C 语义 Web 标准体系、Linked Open Data。阶段特点强调知识标准化、开放性与共享，实现跨平台知识互操作。

3. **知识图谱与工业应用（2012年前后）**  
   2012年 Google 正式发布知识图谱，解决搜索歧义，标志知识图谱从学术走向工业界。技术突破包括图结构表示、数据驱动构建、属性图模型、NLP 自动抽取知识等。

4. **大模型时代深度融合（2020s）**  
   知识图谱与大模型结合，用于解决幻觉问题，增强可解释性与推理能力。典型路线是将知识图谱作为外部知识库，增强大模型生成，即 RAG。

演进洞察是：从封闭的、依赖人工的“专家知识库”，迈向开放的、标准化的、具备网络效应的“全球知识图谱”。

### 知识工程生命周期

#### 知识获取

知识获取是知识工程的起点，核心目标是从异构数据源中提取结构化知识。需要考虑多元数据源输入，不能遗漏重要来源，否则后续清洗、推理会事倍功半。

常见数据源包括结构化数据、半结构化数据、非结构化数据和多模态数据。关键技术包括：

- NLP 深度处理：命名实体识别、关系抽取、句法分析，实现非结构化文本结构化。
- OCR 智能识别：将图像、扫描件、PDF 中文字转化为机器可读文本，打通非数字化内容入口。
- 数据挖掘分析：聚类、关联规则挖掘等，从海量数据中发现潜在规律。
- LLM 大模型赋能：利用大语言模型的理解与生成能力处理复杂语义，实现多模态知识融合抽取。

老师特别提到，OCR 和图片知识抽取很难，但需求量大，若能提高几个点准确率就很有竞争力，甚至可能做线上应用或小创业项目。

#### 知识表示

知识表示的核心目标是将获取的非结构化知识转化为计算机可理解的结构化形式，搭建人类认知与机器智能处理之间的桥梁。核心本质是**本体设计**：设计本体作为知识的“类定义”，明确实体类型、属性关联、关系规则与约束条件，构建知识体系底层骨架与语义基础。

主流知识表示范式包括：一阶谓词逻辑、产生式规则、框架系统、语义网络、RDF/OWL、知识图谱三元组。后续章节详细展开。

#### 知识存储

知识存储的目标是将知识表示后的成果持久化存储，构建稳定、高效、可扩展的存储架构，支持海量知识快速检索、灵活更新与复杂关联查询。

常见存储方式：

| 类型       | 代表系统          | 特点                                                         |
| ---------- | ----------------- | ------------------------------------------------------------ |
| 图数据库   | Neo4j、JanusGraph | 原生图存储，处理实体间复杂关联，支持深度路径查询与图遍历     |
| 关系数据库 | MySQL、PostgreSQL | 结构规整、属性明确，事务机制完善，单表查询高效               |
| 三元组存储 | Jena、Virtuoso    | 遵循 RDF 语义网标准，以“主体-谓词-客体”形式存储，支持标准化、开放共享 |
| 向量数据库 | Milvus、Faiss     | 存储 Embedding 向量，支持海量高维向量相似度快速检索，服务智能问答、语义搜索、推荐 |

老师强调存储重要性：如果某个计算环节超过 50 毫秒，应用就可能不太成功，因为用户可能成千上万并发访问。若系统准确但反馈要 10 天，时效性场景下不可用。12306 早期订票“一直转”的体验就是例子。

#### 知识融合

知识融合常被忽视。仅仅抽取实体和关系并不等于构建完知识图谱，还需要把多源知识打通关联。核心任务包括：

- **实体对齐**：判断不同来源的实体是否指向同一个真实世界对象。例如“苹果公司”“Apple Inc.”以及各地分公司名称，应统一关联到同一个标准实体节点。
- **冲突消解**：针对同一属性在不同数据源中的矛盾值，利用规则或可信度模型判定并保留最优值。例如电商平台与比价网站的商品价格差异，通过数据源权重评估筛选更新。

知识融合的核心使命是消除多源知识异构冲突与冗余，通过实体对齐、属性合并与关系补全，形成统一、标准且高质量的知识库。

#### 知识推理

知识推理基于已有显性知识，通过逻辑推演与算法模型推断隐含知识、补全缺失信息、发现潜在未知关联。主要方法包括：

- **基于规则的推理**：利用 Datalog、SWRL 等形式化逻辑语言定义推理规则，通过演绎推理推导新事实，逻辑可解释性强。
- **基于分布式表示的推理**：将实体与关系映射到低维稠密向量空间，利用 TransE、RotatE 等向量运算捕捉语义关联，计算效率高。
- **基于神经网络的推理**：利用 GCN、GAT 等图神经网络自动提取图结构特征，端到端非线性推理，擅长复杂模糊关联模式挖掘。

推理可支撑知识图谱补全、智能问答、智能决策支持等。例如 A 是 B 的好友，B 是 C 的好友，可预测 A 与 C 可能成为好友，即链接预测。

#### 知识应用

知识应用将构建好的知识融入业务场景，转化为商业价值与用户体验。典型应用包括：

- 智能搜索：基于知识图谱深度语义理解，突破关键词匹配局限。
- 智能问答：赋能客服与虚拟助手，精准理解自然语言意图。
- 个性化推荐：结合用户画像与知识关联挖掘，实现“千人千面”。
- 智能决策支持：金融风控、医疗辅助诊断、企业战略规划。
- 风险智能防控：识别复杂欺诈网络、洗钱行为、信用风险。

老师提到搜索、广告、推荐是互联网最挣钱的三类场景，也是就业岗位较多方向。

### 人工智能概念与发展

#### 智能行为与图灵测试

人工智能是使计算机具有人的智能行为。人的智能行为包括：

1. 通过学习获取知识。
2. 利用知识进行逻辑思维（推理）。
3. 通过自然语言理解进行人际交流。
4. 通过图像理解进行形象思维（联想）。
5. 利用启发式经验方法解决随机变化问题。
6. 利用试探性、创新性方法解决新问题。

概括为：获取知识，进行知识推理、联想或交流，解决随机问题或新问题。老师指出大模型知识量庞大，但知识更新能力差；逻辑推理、编程、数学、自然语言交流表现不错；联想、遗忘、低能耗等方面与人类不同。人类会遗忘，这是特点不一定是优势；人脑思考能耗很低，而大模型能耗和硬件成本高。

图灵 1950 年在论文《计算机能思维吗？》中提出：如果一台计算机能像人一样对话，它就能像人一样思考。图灵定义为：如果机器在某些现实条件下能非常好地模仿人回答问题，使提问者在相当长时间内误认为它不是机器，那么机器就可以被认为能思维。2014年6月7日，图灵逝世60周年纪念日，英国皇家学会举行“2014图灵测试”大会，聊天程序“尤金·古斯特曼”首次通过图灵测试。规则是 5 分钟键盘对话中被误认为人类比例超过 30%，尤金被 33% 评委判定为人类。

#### 大模型能力与幻觉

课程用多个例子说明大模型的能力与缺陷。比如问“ChatGPT 的到来会对银行基层网点转型有何影响”，两个回答一个来自大模型，一个来自专业团队。大模型回答很整齐、很专业，但不够个性化；专业团队回答带有实际服务经验。判断依据之一是“太整齐了”。

大模型还存在明显幻觉：

- 问 iPhone13 性能、拍照体验，它能列参数，但没有真正使用体验。
- 问 1550nm 和 905nm 激光区别，它能给出看似专业回答，并列出参考文献。
- 进一步追问文献网址，它给出链接，但很多链接打不开，文献不存在。
- 还能编造新闻事件。

因此，大模型当前最大缺陷之一是“不知道自己不知道”。虽然可以通过 RLHF 训练，也有研究尝试让模型输出 confidence 或 probability，但幻觉仍未很好解决。这也是知识图谱作为外部知识库、通过 RAG 增强大模型的重要动因。

#### 三大学派

人工智能三大学派：

- **符号主义**：思维基元是符号，思维过程即符号运算；智能核心是知识，利用知识推理求解问题；物理符号系统假设；代表性成果是专家系统。
- **联结主义**：通过神经网络刻画数据与知识，代表性成果是神经网络。当前大模型内核主要基于联结主义。
- **行为主义**：基于智能控制系统的理论、方法和技术，以生物控制系统智能行为模拟为重点，研究拟人智能控制行为，与具身智能、自动化理论相关。

老师强调三大学派不应被当作对立逻辑，而应融合互补。大模型离不开符号知识支撑，如外挂知识库；内核是神经网络；具身智能则结合控制与行为主义。

#### 知识系统与结构

知识系统包括专家系统、知识库系统、智能决策系统等：

- **专家系统 ES**：利用专家知识解决特定领域问题的计算机程序系统。
- **知识库系统 KBS**：把知识以一定结构存入计算机，进行知识管理和问题求解，实现知识共享。
- **智能决策系统 IDS**：由数据库、模型库、知识库、人机交互等组成，解决半结构化决策问题，提高科学决策水平。

知识系统基本结构包括：

- 知识库：由事实和规律两类知识组成。
- 推理子系统：对知识库中的知识进行推理。
- 人机接口：输入用户要求，输出推理解释。
- 知识获取子系统：把专家知识整理形式化后输入知识库。

进一步还有：

- **元知识与领域知识**：元知识是关于知识的知识，即关于领域知识的说明和使用知识。元知识系统可看成元级知识与领域级知识两级组合。
- **多层知识结构**：至少包括表层、深层。表层系统包含各领域基本知识和经验性、判断性知识；深层系统包含原理性知识和常识。表层知识直接解决实际问题，深层知识弥补表层不足。
- **分布式系统结构**：由多个较小规模知识系统组成，每个小系统具有部分问题状态数据和部分领域知识。分布式系统大多利用“黑板”结构：各专家分散在不同位置，通过共享黑板交换数据、结论和问题。
- **多智能体系统结构**：Agent 是具有智能的个体，具有社会交互性和智能性。斯坦福小镇（Stanford + Google 2023）是早期代表性工作。老师借此强调大模型时代研究节奏很快，好想法要尽快做，否则容易被人抢先。

### 知识计算

#### 技术框架：知识层、模型层、算子层

知识计算的核心是“机器如何利用知识进行计算”。首先需要将知识表达为机器可理解和处理的数学模型，其次针对特定模型高效求解。

知识计算技术框架分为三层：

1. **知识层**  
   知识是知识参与计算的底层基础，是人类在实践中认识客观世界的成果。参考哲学、心理学分类，通常分为事实性知识、概念性知识、程序性知识、元认知知识。行业生产活动沉淀的知识包括生产日志、手册、经验、流程等。例如生产基本元素属于事实性知识，生产流程属于程序性知识，机理模型属于概念性知识。

2. **模型层**  
   模型是知识参与计算的载体，用数学模型刻画行业知识并有效参与计算。常用模型包括代数方程模型、微分方程模型、统计模型、图模型等。知识图谱可通过图模型构建，石油勘探测井中的伽马射线通量计算模型属于微分方程模型。模型可分类为线性/非线性、宏观/微观、确定/随机、白盒/黑盒、离散/连续等。

3. **算子层**  
   算子是知识参与计算的手段，是机器对知识进行建模和求解的操作。算子可规范化为两类：建模算子聚焦将数据转换成可计算模型；求解算子聚焦利用 AI 技术对模型高效精准求解。常见算子包括高斯消元、最小二乘、梯度下降、有限差分、有限元、变分、最大期望、遍历算法、社群挖掘、重要度分析、单纯形算法、内点算法、图表示学习、分支定界、模拟退火、禁忌寻优等。

形象比喻：知识层相当于生产资料，模型层相当于生产工具，算子层相当于生产过程。数据已被我国视为第四生产要素。

#### 知识分类

哲学界对知识的分类较为抽象。柏拉图认为知识是经过证实的真实信念；一条陈述成为知识需满足：被验证过、正确、被人们相信。亚里士多德将知识分为对不可变事务的认识（理论）和对可变事务的认识，后者又分实践与创造。波兰尼将知识分为显性知识与隐性知识：显性知识可用书面文字、图表、数学公式表述；隐性知识是在行动中拥有、未被表述的知识。

OECD 将知识分为：

- know-what：关于客观事实的知识。
- know-why：自然规律和原理方面知识。
- know-how：技术诀窍、技能和能力方面知识。
- know-who：知道何人具有何种知识和能力的知识。

课程重点采用事实性知识、概念性知识、程序性知识、元认知知识划分：

- **事实性知识**：学习者通晓一门学科或解决问题必须知道的基本要素，如领域术语、特定细节、事物要素。交通行业中的拥堵指数、自由流速度、二次排队率；油气行业中的低阻油层、束缚水饱和度、波阻抗；医疗行业中的分子组学、临床指南等。
- **概念性知识**：较为概括、组织性的结构化知识，包括理论模型、先验规则等。例如交通信控场景中最大信控周期不能超过 180 秒，相位最小绿灯不宜小于 25 秒，相邻周期同相位变化不宜大于 10 秒；油气行业中描述测井曲线正演过程的 Maxwell 方程、波动方程、Archie 公式等。
- **程序性知识**：关于如何做某事的一套程序或步骤，如汽车维修工作流程、焦化行业配煤流程、政务工单处理流程、知识图谱构建流程等。
- **元认知知识**：关于认知自身的知识。

#### 知识图谱构建与应用

通过图模型建模算子实现知识图谱构建，通常包括：

1. **本体构建算子**  
   本体也称知识图谱的模式（Schema），是对图谱数据的模式约束。本体构建需要定义领域范围内概念、实体、属性、关系、事件等元素。

2. **结构转换算子**  
   输入原始文本或图片数据，输出实体、属性、关系、事件。技术包括命名实体识别、关系抽取、事件抽取。

3. **数据去重与知识融合算子**  
   将两个或多个图谱合并时，需要识别指向同一对象的实体并去重，例如“上海”和“沪”等。可通过相似性计算、Bloom Filter 等方法过滤。

4. **图模型求解算子**  
   组合图遍历、图表示学习等算子实现知识推荐。结合图传播算法形成用户兴趣扩散，实现个性化商品推荐，相比传统推荐系统能大幅提升转化效果。

典型应用包括：

- 智能搜索、智能问答、个性化推荐。
- 影响力最大化：在视频网络或社交网络中选取种子节点投放广告，不一定要选最大 V，选择多个中等规模 V 可能效果更好、成本更低。
- 金融事理图谱：每个节点是事件，边表示事件间顺承、因果、时序关系。例如粮食减产 → 食品价格上涨 → 物价上涨 → 通胀 → 政策紧缩 → 降准；或农产品涨价预期、社会不安定、抗议、股市下跌等事件链。可用于投资决策、风险推演。

#### 反洗钱与环路检测

金融知识计算的重要应用是反洗钱。洗钱是金融行业最难发现的犯罪行为之一。常见手段是**环路汇款**：资金在繁多账号间流转，形成环路链条，最终回到犯罪者手中。例如账号 A 转账给账号 B，B 转给 C，C 又转给 A；小明持有 A，小李持有 B，X 持有 C，形成洗钱关系。虚假交易、电商刷单也类似：资金先流向某账户，再通过其他方式转回。

德勤《优化打击金融犯罪的全球框架》报道：全球每年洗钱金额接近 1.87 万亿欧元，相当于全球 GDP 的 2%—5%。反洗钱中知识包括监管法规、客户/账户/公司/金融工具属性信息、交易关系、洗钱手段、政治人物或制裁名单联系等。

静态有向图中找环的一个经典方法：

- 若某点只有出边没有入边，则它不可能参与环，可删除。
- 若某点只有入边没有出边，也不可能参与环，可删除。
- 删除后可能暴露新的只有入边或只有出边的点，迭代删除。
- 直到图中没有可删点。若还有剩余点且每点都有入边和出边，则可能含有环。

动态金融网络中，边实时产生，如何高效实时检测新环是很有挑战的研究话题。好的知识计算方案可使效率比传统图数据库在发现可疑洗钱行为上快 10 倍以上。

### 知识表示方法

#### 数理逻辑：命题逻辑与谓词逻辑

知识表示的目的是让计算机理解和推理，必须将自然语言知识形式化、数字化。数理逻辑也称符号逻辑，是人工智能的重要理论基础。逻辑学基础研究是形成概念、作出判断、进行推理。

**命题逻辑**中五种联结词：

- $\land$：与
- $\lor$：或
- $\neg$：非
- $\to$：如果……那么，即蕴含
- $\leftrightarrow$：等价，即当且仅当

优先级从高到低为：$\neg$、$\land$、$\lor$、$\to$、$\leftrightarrow$。同级联结词先出现先优先。

例子：如果 $a$ 是偶数，那么 $a^2$ 是偶数。令 $p$ 表示“$a$ 是偶数”，$q$ 表示“$a^2$ 是偶数”，则 $p \to q$。

“人不犯我，我不犯人；人若犯我，我必犯人”：令 $p$：人犯我，$q$：我犯人，则可表示为 $(p \to q) \land (\neg p \to \neg q)$，即 $p \leftrightarrow q$。

命题逻辑常见等价公式：

- 析取交换律：$p \lor q \leftrightarrow q \lor p$
- 合取交换律：$p \land q \leftrightarrow q \land p$
- 析取结合律：$(p \lor q) \lor r \leftrightarrow p \lor (q \lor r)$
- 合取结合律：$(p \land q) \land r \leftrightarrow p \land (q \land r)$
- 分配律：$p \lor (q \land r) \leftrightarrow (p \lor q) \land (p \lor r)$
- 分配律：$p \land (q \lor r) \leftrightarrow (p \land q) \lor (p \land r)$
- 双重否定：$\neg \neg p \leftrightarrow p$
- 德摩根律：$\neg(p \lor q) \leftrightarrow \neg p \land \neg q$
- 德摩根律：$\neg(p \land q) \leftrightarrow \neg p \lor \neg q$
- 蕴含转换：$p \to q \leftrightarrow \neg p \lor q$
- 蕴含转换：$p \to q \leftrightarrow \neg q \to \neg p$
- 等价转换：$p \leftrightarrow q \leftrightarrow (p \to q) \land (q \to p)$
- 等价转换：$p \leftrightarrow q \leftrightarrow \neg p \leftrightarrow \neg q$
- 与转或：$\neg(p \land q) \leftrightarrow \neg p \lor \neg q$

范式是公式的标准形式，有两种基本范式：

- **合取范式**：一些简单析取式的合取式。例如 $(p \lor q) \land (p \lor \neg q)$。
- **析取范式**：一些简单合取式的析取式。例如 $(p \land q) \lor (p \land r)$。

**谓词逻辑**主要研究一阶谓词逻辑，考虑全称量词 $\forall$ 和存在量词 $\exists$。量词否定公式：

$$\neg(\forall x)P(x) \leftrightarrow (\exists x)\neg P(x)$$

$$\neg(\exists x)P(x) \leftrightarrow (\forall x)\neg P(x)$$

谓词公式范式包括：

- **前束范式**：一切量词都未被否定地处于公式最前方，且其管辖域为整个公式。例如 $(\forall x)(\exists y)(p(x,y) \to q(x,y))$。
- **Skolem 范式 / 存在前束范式**：所有存在量词都在全称量词之前的前束范式。

#### 产生式规则与推理

产生式规则形式为：

$$\text{IF conditions THEN actions}$$

conditions 是条件集合，又称 LHS；actions 是动作序列，又称 RHS。例子：IF 有一个学生名为 $x$，THEN 向事实集中加入一个事实，表示有一个名为 $x$ 的人。

**正向推理**：逐条搜索规则库，对每条规则前提条件检查事实库。若前提子项未全部存在，放弃该规则；若全部存在，执行规则，把结论放入事实库。反复循环，直到推出目标或事实库不再更新。

例子：规则库为

1. $A \land B \to G$
2. $C \land D \to A$
3. $E \to D$

事实库初始为 $B,C,E$。先检查规则 3，$E$ 存在，推出 $D$，事实库变为 $B,C,E,D$；再检查规则 2，$C,D$ 存在，推出 $A$，事实库变为 $B,C,E,D,A$；再检查规则 1，$A,B$ 存在，推出 $G$。最终事实库为 $B,C,E,D,A,G$。

**反向推理**：从目标出发，寻找以目标为结论的规则，递归检查该规则前提。若前提中某子项是另一规则结论，再找以它为结论的规则。目标改变过程为从 $G$ 到 $A,B$，再到 $C,D$，再到 $E$，若已知 $E$，则回溯判断成立。反向推理是目标驱动，更有针对性。

#### 语义网络

语义网络把概念用节点表示，概念之间的关系用边表示，形成图结构。推理表现为对节点访问和关系检索，可回答两类问题：

1. 从概念节点间问它们之间关系。
2. 通过概念和关系问有关节点。

例子：“海浪猛烈地晃动轮船”。语义网络中：

- “海浪” isa “某港海浪”
- “轮船” isa “某港轮船”
- “晃动”动作主体是“海浪”，动作对象是“轮船”，动作方式为“猛烈”。

可回答：

- 海浪和轮船有什么关系？某港海浪晃动某港轮船。
- 怎样晃动？猛烈地晃动。
- 晃动哪些轮船？某港轮船。

#### 框架与剧本

**框架**由一组描述物体各方面的槽组成，每个槽可包含若干侧面，每个侧面有名字和值。形式为：

- 框架名
  - 槽名1
    - 侧面11：值11
    - 侧面12：值12
  - 槽名2
    - 侧面21：值21
    - 侧面22：值22

槽值类型包括：具体值、默认值、过程值、另一框架名、空待填入。框架推理主要形式是填充槽值。

例子：“王强的行动和音量像消防车。”王强框架有性别、行动、音量、进取心等槽，消防车框架有颜色、行动、音量、载物等槽。匹配行动和音量两个槽，王强框架没有槽值，消防车框架有槽值，填充后得到：王强的行动是快的，音量是极高的。

框架继承分直接继承和条件继承。直接继承如下层框架从上层继承所有属性值和条件，如“墙”继承“房子”的所有属性。条件继承如时序继承。例子：旧中国框架：政体资产阶级专政，面积960万平方公里，人口4亿5千万，领导党派国民党；新中国框架：政体人民民主专政，面积960万平方公里，人口4亿5千万，领导党派共产党。面积、人口可继承，政体、领导党派替换。

**剧本**描述一定范围内一串原型事物的结构。组成包括：

- 开场条件：事件发生前必须满足的条件，如肚子饿了、有钱。
- 结局：事件发生后通常成为现实的情况，如不再饿、花了钱。
- 道具：与事件有关的物体，如餐桌、菜单、食物。
- 角色：事件中人物，如经理、顾客、服务员。
- 线索：事件时序模式，如小食店、餐厅、酒家。
- 场次：事件发生顺序，每个场次可用框架描述。

饭店剧本例子：

- 第一场：进入饭店。事件：走进饭店，寻找空桌，走到桌旁，坐下。
- 第二场：点菜。事件：服务员送菜单，顾客读菜单，选定菜，告诉服务员。
- 第三场：吃饭。事件：服务员上菜、饭，顾客吃饭。
- 第四场：离开。事件：服务员送来账单，顾客付钱，顾客离开饭店。

剧本推理可解释故事中没有提及的事件。问题：李杰吃了什么？故事只提“要”没提“吃”，答：烤鸭、菜和汤。谁给李杰菜单？答：服务员。谁上的菜？答：服务员。李杰付钱没有？答：付了钱。剧本能充实故事、解释故事，预见不直接观察到的事件，说明连贯事件关系，集中注意特殊事件。

#### 本体、RDF 与 OWL

**本体**起源于哲学，是形而上学的重要分支，研究“存在”及其基本分类，试图回答什么刻画了存在、最终什么是存在。计算机科学中，本体是一个工程制品，包括一个词汇集，用于描述某个领域的一个特殊视角；词汇集含义的显式说明；经常包含基于分类的信息；约束用于捕获领域背景知识。理想情况下，本体应捕获共同兴趣领域中的共享理解，并提供形式化、机器可操纵的模型。

一个完整本体由五类基本元素构成：

$$O ::= \{C, R, F, A, I\}$$

- $C$：概念，通常按一定关系形成分类层次结构。
- $R$：关系，表示概念之间的一类关系，如 subclass-of、part-of。
- $F$：函数，是一种特殊关系，其中第 $n$ 个元素 $C_n$ 相对于前面 $n-1$ 个元素唯一确定。
- $A$：公理，概念或概念之间关系所满足的永真式。
- $I$：实例，属于某概念类的基本元素，即具体实体。

车辆本体例子：车类，轿车和卡车是其子类，轿车有价格、型号等属性，奇瑞、别克是实例，售价8万。

**RDF** 是资源描述框架，用三元组 $(S,P,O)$ 编码陈述。通常翻译为主体—谓词—客体，不要叫主语—谓语—宾语。例子：长江长度6300公里，起点青藏高原，终点东海。所有 RDF 知识都是三元组形式，但三元组对时间、空间维度和多元关系刻画能力有限，可能需要引入超图概念。

**OWL** 是 W3C 推荐的 Web 本体语言，由 OWL Lite、OWL DL、OWL Full 三个语言构成，现在是 OWL2。OWL 基于描述逻辑，是知识图谱语言中最规范、最严谨、表达能力最强的语言。它基于 RDF 语法，使文档具有语义理解结构基础，促进统一词汇表使用，定义丰富语义词汇，允许逻辑推理。

描述逻辑系统包括四个基本组成部分：

1. 最基本的元素：概念、关系和个体。
2. TBox 术语集：概念术语的公理集合。
3. ABox 断言集：个体的断言集合。
4. TBox 和 ABox 上的推理机制。

概念解释为一个领域的子集，如学生 $\{x \mid student(x)\}$；关系解释为该领域上的二元关系，如朋友 $\{\langle x,y \rangle \mid friend(x,y)\}$；个体是一个领域内的实例，如小明。

TBox 语言引入概念以及关系名称，包含声明包含关系的公理。例子：$Mother \sqsubseteq \exists has\_child.Person$。ABox 语言包括概念断言和关系断言。概念断言表示对象是否属于某概念，如 $Mother(Alice)$、$Person(Bob)$；关系断言表示两个对象是否满足特定关系，如 $has\_child(Alice,Bob)$。

描述逻辑知识库即 TBox + ABox。TBox 是泛化知识，描述概念和关系，称为公理；由于概念间存在包含关系，TBox 知识形成类似格（Lattice）的结构。ABox 是具体个体信息，包含外延知识，又称断言，描述论域中特定个体。

描述逻辑语义构造算子包括：原子概念、原子关系、合取、析取、否定、存在量词、全称量词。对应 OWL 词汇包括：

### 知识推理

#### 可满足性、分类与实例化

推理是通过各种方法获取新知识或结论，这些知识和结论满足语义。OWL 本体推理包括：

- **可满足性 satisfiability**：判断本体是否不可满足。例如 $Man \sqcap Woman$ 不可满足，因为男性和女性交集为空。若规则要求某个体既是男性又是女性，则至少一个不成立。
- **分类 classification**：计算新的概念包含关系。例如 $Mother \sqsubseteq Women$，$Women \sqsubseteq Person$，则 $Mother \sqsubseteq Person$。这类似传递推导。
- **实例化 materialization**：计算新的类实例信息。例如 $Mother \sqsubseteq Women$，$Mother(Alice)$，则 $Woman(Alice)$。也可计算新二元关系：$has\_son(Alice,Bob)$，$has\_son \sqsubseteq has\_child$，则 $has\_child(Alice,Bob)$。

关系也有上下位关系。例如 has_son 是 has_child 的子关系，基于关系传导可推出新三元组。老师指出，这面向智能体记忆、知识抽象、归纳总结有重要支撑。

#### 演绎、归纳与类比

形式逻辑研究人的思维形式及规律，主要研究形成概念、作出判断、进行推理。推理常见分为：

1. **演绎推理**：从一般现象到个别或特殊现象。专家系统基本属于演绎推理，核心是假言推理。

   - 肯定前件假言推理：$P \to Q$，$P \vdash Q$。例如：如果今天是星期二，John 会去工作；今天是星期二；所以 John 会去工作。
   - 否定后件假言推理：$P \to Q$，$\neg Q \vdash \neg P$。例如：如果下雨，天上有云；天上没有云；所以没有下雨。
   - 三段论：$P \to Q$，$Q \to R \vdash P \to R$。例如：如果 Larry 生病，他会缺席；如果他缺席，他会错过课程；所以如果 Larry 生病，他会错过课程。
   - 假言易位推理（拒取式）：$P \to Q$，$\neg Q \vdash \neg P$。

   在 RDF/OWL 中演绎推理例子：投资 rdfs:domain 投资人；投资 rdfs:range 公司；谷歌 rdf:type 人工智能公司；人工智能公司 rdfs:subclass 高科技公司；大卫·切瑞顿投资谷歌。于是推出：谷歌 rdf:type 高科技公司；大卫·切瑞顿 rdf:type 投资人。演绎推理不存在可解释性问题。

2. **归纳推理**：从个别或特殊现象到一般现象。

   - 数学归纳法：推导严格，结论可靠。
   - 枚举归纳推理：$S_1$ 是 $P$，$S_2$ 是 $P$，……，$S_n$ 是 $P$，且没有相反事例，所以 $S$ 类事物都是 $P$。结论是或然的。
   - 老师指出很多科学结论具有或然性，如牛顿第一定律有前提条件。

3. **类比推理**：从个别或特殊现象到个别或特殊现象。若 A 事物有 abcd 属性，B 事物有 abc 属性或相似属性，则推断 B 也可能有 d 属性或相似属性。结论带有或然性。

总结对比：

- 演绎推理结论没有超出已知知识范围，只能解释一般规律中的个别现象；前提和结论有必然联系，只要前提为真，结论一定为真。
- 归纳推理和类比推理结论超出已知知识范围，能创造新知识，使科学得到新发展；但前提和结论不能保证必然联系，具有或然性，需要严格验证和证明。

#### 兼并重组套利案例

课程用 OWL 本体推理给出一个金融选股套利策略：

- 策略思想：与大盘股公司兼并重组的上市企业有很高预期收益。
- 形式化：$Emerge.BigCapital \sqsubseteq ValueSecurity$。
- 定义大盘股：上证50和沪深300指数中的标的属于大盘股。$SZ50 \sqsubseteq BigCapital$，$HS300 \sqsubseteq BigCapital$，$SZ180 \sqsubseteq HS300$。
- 已知：$merge(SZ300377, SH600570)$，即赢时胜和恒生电子在区块链方面有业务兼并。
- 又知：$SZ180(SH600570)$，恒生电子是上证180成分股。
- 推理：$HS300(SH600570)$，$BigCapital(SH600570)$，$ValueSecurity(SZ300377)$。
- 结论：SZ300377 赢时胜在短期内是一家高收益公司。

这本质上是利用基于消息面的套利，推理机可以完成复杂股票筛选过程。老师强调，如果规则只有你知道而别人不知道，就可能赚钱。

#### 基于图的推理

基于图的推理基本思想是：将连接两个实体的路径作为特征，预测其间可能存在的关系。PPT 给出文学人物关系例子：Charles Dickens 是 Novel? 写了 A Tale of Two Cities；Jane Eyre 是 Novel? 写了 Charlotte Bronte；Charlotte Bronte HasFather Patrick Bronte。可通过路径特征预测 Profession 等缺失关系。这类思想与知识图谱链接预测、路径排序、图神经网络推理相关。
