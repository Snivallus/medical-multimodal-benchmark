## 2. 指标

- 单题得分：`score = clip((TP − FP) / |G|, 0, 1)`，不定项、错选倒扣，全对为 1。
- 主指标：`Δacc = mean(score_photo) − mean(score_text_b)`，逐题配对。
- 附表指标：主诊断命中率（`main_diagnosis` 是否被选中）、`Δ > 0` 的题目占比、`Δ < 0` 的题目占比。
- 置信区间：对题目做 1000 次 bootstrap，报 95% 区间；同时报配对符号检验的 p 值。
  单一模型、单次采样、temperature 0，**两个数差 0.02 不要当结论**。

## 6. 结论的三种走向（先写死，避免事后编故事）

1. **口径 B 的 Δacc 显著为正（CI 不含 0），口径 A ≈ 0** → 旧结果的零增益来自图注泄漏；
   裁掉图注后影像信息才真正被用上。这是最理想、也最可能的结果，因为 5 例试点里
   唯一的正增益例子正是"图里有真实病灶、图上没写字"的那类。
2. **口径 B 仍然 ≈ 0** → 图像对 `Qwen3.8-Max` 在这批题上没有增益。这是一个**有价值的负结果**：
   说明多模态模型在真实病例诊断题上并没有用上影像，proposal 里"图像是否必要"的假设不成立。
   此时不要再调 prompt 去追一个正数，而是把这个负结果讲清楚（并讨论仍泄露/裁不掉的 C 档题的影响）。
3. **口径 B 显著为负** → 图像成了干扰（图注之外的视觉噪声、低质量照片、图文不符）。
   需要按 4.1 的 B 档拆开看，很可能是"临床照片/术中照"造成的。

**无论哪种走向，都要报口径 A**：它是这个数据集最有说服力的一个发现（155 张图里大半带图注），
本身就可以单独成一段。
