## A 组选题: 中文真实病例的多模态诊断推理对抗评测

课程: 认知智能前沿技术与实践.   
赛道一 (AB 对抗) A 组 (任务设计与数据构建组).

**定位**: 使用爱爱医网站的真实病例构建一个医学多模态评测集，由若干道不定项选择题构成， 
题干由文本和图像两种模态构成，用于检验医学多模态模型究竟是结合病例文本信息和医学影像进行推理， 
还是无视医学影像，过分依赖它 "背下来" 的中文文本先验.

**对应课程任务方向**: $8$ (其他自选题目)，陷阱设计思路可复用于方向 $3$、$4$.

### 数据来源

- 原始站点: [iiyi.com](https://bingli.iiyi.com/) (爱爱医) 病例分享.
- 数据构建管线: [Snivallus/iiyi_dataset](https://github.com/Snivallus/iiyi_dataset)  
  (爬虫 → Baichuan2-13B 过滤 → DeepSeek 结构化改写 → 终筛).
- 数据副本: [SnivellusSnape/iiyi_dataset](https://huggingface.co/datasets/SnivellusSnape/iiyi_dataset).
- 规模: `case_with_images.json` $2395$ 例，图像引用 $4334$ 条 (约 $1.81$ 张/例);  
  另有 `case_without_images.json` $1040$ 例纯文本病例，可直接作为 "遮住图片" 的对照组.
- 字段结构: `标题` `关键词` `基本信息` `主诉` `现病史` `既往史` `个人史` `家族史`  
  `查体` `辅助检查` `诊断依据` `诊断结果` `治疗方案` `治疗经过`.



### 评测集形式

从 $2395$ 个带图病例中筛选数百例 "医学影像对得出正确诊断相对关键" 的高质量病例， 
先做小规模试点 (约 $100$ 例) 验证流程与标注一致性，再扩充到正式规模.

每例改编为不定项选择题，题干由文本与图像两种模态构成，并按以下三种版本同时发布:

| 版本 | 题面 | 用途 |
| ---- | ---- | ---- |
| 图文齐备 | 病例文本 + 医学影像 | 主评测 |
| 纯文本 | 病例文本，遮住图像 | 图像必要性对照 |
| 图文冲突 | A 病例影像 + B 病例文本 (诊断相近但不同) | 抗误导评测 |

正式入集前，每例需通过图像必要性检验与人工审核，并标注陷阱类型.



### 指标: 图像必要性

现有模型的认知缺陷: 即使视觉信息可用，医学 VLM 的决策仍被文本模态主导， 
对文本过度依赖，无视影像证据.

对每一道题 $i$，定义

$$
\Delta \mathrm{acc}_i = \mathrm{acc}_i(\text{图文齐备}) - \mathrm{acc}_i(\text{纯文本, 遮住图片})
$$

- 若模型真的在使用图像，则 $\Delta \mathrm{acc}$ 明显为正;
- 若模型在吃文本先验，则 $\Delta \mathrm{acc} \approx 0$.

并由 $\Delta \mathrm{acc}$ 定义样本级图像必要性:  
只有 $\Delta \mathrm{acc}_i > 0$ (在若干开源模型上稳定成立，且经过人工审核) 的样本才进入正式评测集.

配套三个一致性检验:

| 检验 | 做法 | 暴露的缺陷 |
| ---- | ---- | ---------- |
| 图文冲突 (Selective Modality Shifting) | 把 A 病例的影像与 B 病例的临床文本配对 (B 与 A 诊断相近但不同)，要求模型判断"该图是否支持文本给出的诊断"，三分类为支持、反驳、信息不足 (复用课程任务 $4$ 的口径) | 文本先验支配、无视影像证据 |
| 图像置换翻转率 | 交换两例图片后，答案是否随之改变; 一直不变说明模型没看图 | 图像未被使用 |
| 语义等价提示改写 | 同一问题的多种中文表述，答案是否稳定 | 提示敏感性 |

不定项选择题还须报告主要诊断命中率，并做选项位置平衡，避免位置偏置干扰上述指标.



### 给 B 组的方向建议

可以使用 [MedXpertQA](https://medxpertqa.github.io/) 等多模态医学选择题数据集对 [Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct) 等开源 VLM 模型进行微调， 
或是以开源 VLM 模型为基础模型搭建一个 Harness， 
通过连接外部医学知识库或轻量的医学影像模型等工具来提高答题准确率.

A 组计划在第 $8$ 周前交付: 数据集与 JSON schema、评测脚本、指标定义、  
三种版本题面的 baseline 结果 (纯文本与图文对照)、陷阱清单.  
B 组据此调优后，在第 $10$ 周展示相对中期表现的提升幅度.
