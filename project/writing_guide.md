## 中文文档撰写风格规范

### 文档命名规范

| 类别 | 模式 | 示例 |
|------|------|------|
| 指南 | `*_guide.md` | `code_agent_guide.md`, `git_github_guide.md` |
| 规则 | `*_rule.md` | `curling_rule.md` |
| Python 相关 | `python_*_guide.md` | `python_coding_guide.md`, `python_env_guide.md` |
| 非技术类 | 直接用英文描述 | `writing_guide.md` |

所有文档统一使用英文小写字母命名，单词之间用下划线分隔.

### 标点规范

| 标点                                             | 使用                               |
| ------------------------------------------------ | ---------------------------------- |
| 逗号 / 顿号                                      | 全角 `，` `、`                     |
| 句号 / 冒号 / 分号 / 括号 / 引号 / 问号 / 感叹号 | 半角 `.` `:` `;` `()` `""` `?` `!` |

### 中英文混排

中文与英文、数字、公式、代码之间均加空格，例如:

- 使用 Softmax 函数
- 详见第 1 章
- 输入尺寸 $n_\mathrm{in}$, 卷积核大小 $k$
- 使用 `git add .` 命令

### 外国人名地名

外国人物和地名使用原文英文名称，不要使用中文译名，例如:

- 使用 `Yann LeCun` 而非 "杨立昆"
- 使用 `New York` 而非 "纽约"

### 数学符号与数字

文档中出现的数学符号和数字均使用 LaTeX 行内公式表示，即用 `$...$` 包裹，例如:

- 使用 `$v_0$` 而非 `v0` 或 `$v0$`
- 使用 `$4$` 局 而非 `4` 局
- 使用 `$[0, 6]$` 而非 `[0, 6]`
